# Store Metadata Draft

## App Name

Очаг

## Short Description

Семейные задачи, цели и награды в одном спокойном приложении.

## Full Description

Очаг помогает семье видеть общие дела, договоренности и маленькие победы в одном месте.

В приложении можно создавать задачи, обсуждать инициативы, копить прогресс к семейной цели, выдавать награды и смотреть историю событий. Взрослые управляют правилами и подтверждениями, а дети видят свои задачи, идеи, награды и прогресс понятным способом.

Очаг не заменяет живые разговоры в семье. Он помогает не потерять договоренности, сделать вклад каждого заметнее и добавить немного игрового настроения в повседневные дела.

## Key Features

- Семейный профиль с ролями: владелец, взрослый, ребенок.
- Задачи с исполнителями, статусами и подтверждением выполнения.
- Инициативы для семейных предложений и решений.
- Награды, запросы наград и подтверждение получения.
- Общая семейная цель с вкладом участников.
- Рейтинг, уровни и опыт для мягкой игровой мотивации.
- История событий, чтобы видеть, что уже произошло.
- Уведомления о важных действиях.
- Главный экран с кратким обзором задач, ожиданий, цели и последних событий.

## Beta Note

Это первая beta-версия Очаг. Основные семейные сценарии уже доступны, но часть процессов еще может быть упрощена.

В beta особенно важно проверить:

- регистрацию и вход;
- создание и вступление в семью;
- задачи и подтверждение выполнения;
- инициативы и решения;
- награды и запросы;
- семейную цель;
- историю, рейтинг и уведомления;
- работу приложения на реальных семейных сценариях.

Некоторые сервисные действия в MVP могут использовать временные технические процессы, например ссылки из логов backend вместо полноценной email-доставки.
